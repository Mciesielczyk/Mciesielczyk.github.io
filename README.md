#  Portfolio 

 gotowe, w pełni interaktywne portfolio z systemem motywów i wielojęzycznością. Strona działa dynamicznie – wszystkie treści są wczytywane z plików tekstowych, więc nie trzeba grzebać w kodzie HTML, żeby zmienić opisy.

##  Technologie
* **HTML / CSS** – struktura i  style.
* **JavaScript** – cała logika, zmiana języków i renderowanie danych.
* **Bootstrap** – responsywny układ.

Repozytorium jest przygotowane tak, aby każdy mógł je łatwo dostosować pod siebie.

**Jeśli chcesz zmienić treści na stronie, wystarczy, że edytujesz pliki w folderze `data/`:**
1.  **Dane profilowe, skille i doświadczenie**: Edytuj `data/pl/config.json` (dla polskiej wersji) oraz `data/en/config.json` (dla angielskiej).
2.  **Projekty**: Edytuj odpowiednio `projects.json` w folderach językowych.
3.  **Zdjęcia**: Wrzuć swoje grafiki do folderu `assets/images/` i podaj ścieżkę do nich w plikach JSON.

4. Strona automatycznie odświeży treść po zapisaniu zmian.

##  Motywy
Strona posiada wbudowany przełącznik motywów:
* **Creamy**
* **Slate** 
* **Nordic** 
* **Cyber** 
* **Sand**

##  Hosting
Repozytorium jest przystosowane do działania jako **GitHub Pages**. Po wrzuceniu plików na swoje konto, wystarczy włączyć opcję "Pages" w ustawieniach repozytorium, a Twoja strona będzie dostępna pod publicznym adresem.
